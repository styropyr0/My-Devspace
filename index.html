I write firmware, device drivers, rendering code and, once, a Linux small enough to boot on a thumb-sized microcontroller. Most of what I build starts from a datasheet or a blank file rather than a framework: sensor drivers written register by register, a filesystem for a 4 KB EEPROM, shaders that refract whatever sits behind them. I like knowing what every layer underneath my code is doing, and I usually find out by writing that layer myself.

Most of my work is in C and C++. Outside of that, it's Kotlin and Java on Android, Go and Python on servers, and whatever the problem needs in between.

01Selected work

Linux on the XIAO RP2350

Operating system port · private

A Linux build cut down to fit the RISC-V side of the Seeed Studio XIAO RP2350. The RP2350's Hazard3 cores have no MMU, the board has 520 KB of on-chip SRAM, and there is no external PSRAM to fall back on, so every part of the image has to justify its size: kernel configuration, init, userspace and the boot path out of flash.

Xiao

Android app · closed source · on Google Play

A toolkit for testing connected hardware and network services from a phone. It talks BLE GATT, Bluetooth Classic RFCOMM, raw TCP and UDP, HTTP, WebSocket and MQTT, with typed payloads saved per device.

Beyond the client side it can play the other end of the conversation: a BLE peripheral emulator, an embedded Ktor HTTP server with SQLite, an HTTPS intercepting proxy with its own CA, an ADB client implemented over TCP/TLS without the adb binary, and an NFC reader/writer. Automations are built on a node canvas with conditions, loops and joins, and can be triggered by schedules, MQTT messages, BLE notifications or polled APIs.

Visionary

Self-hosted observability · open source

Monitoring for APIs, servers and frontends: request logs, errors, uptime checks, alerting and host metrics, all stored in one SQL database the operator chooses (PostgreSQL, MySQL, SQLite or Cloudflare D1). Server SDKs for Go, Node, Python, Ruby, Java and .NET write directly to the database; browser, iOS and Android SDKs and any OTLP exporter post to the server.

A systemd host agent reports machine and container metrics plus security events like failed SSH logins. An analyst answers questions such as “why did p95 latency spike at 14:00” by running a bounded number of read-only SQL queries against Visionary's own tables, with IPs, headers and bodies masked before anything leaves the server.

Prismal & PrismalAGSL

Android rendering libraries · open source

Real-time “liquid glass” for Android: backdrop blur, edge refraction, chromatic aberration, Fresnel and specular terms, with spring-driven press interactions. The first version renders through OpenGL ES 2.0 for the View system. The second is a rewrite for Jetpack Compose on AGSL and RuntimeShader, which samples the backdrop inside the graphics pipeline instead of capturing it separately, so it is much lighter on GPU and memory. It falls back gracefully on devices without AGSL.

Working on it led to writing an AGSL grammar for syntax highlighting and proposing AGSL as a language to GitHub Linguist.

MjolnFS

Filesystem for I²C EEPROM · open source

A small structured filesystem for AT24C-series EEPROMs, from 4 KB to 512 KB parts. Create, read, rename, delete and list files, with a versioned on-disk format: mounting checks the boot sector and refuses images it doesn't understand rather than guessing. Includes a serial shell for poking at the volume by hand. Published in the Arduino Library Manager.

Imaging with an optical mouse sensor

Hardware experiment · open source

An optical mouse is a tiny camera. Reading the MX8650's registers directly over its serial interface exposes the raw pixel array, which I rendered to a display as an image. The same frame data turned out to be sensitive enough to detect small vibrations, so the sensor doubles as a crude interferometer. The register access later became a standalone driver library.
